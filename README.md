# 인융대의 밤 입장 체크

2026 인공지능융합대학 연합 기말고사 간식행사 「인융대의 밤」(12/1, 노천극장) 입장 체크 시스템.
폰으로 도서관 모바일 이용증 QR을 찍으면 인융대 소속 여부, 학생회비 납부 여부, 중복 수령 여부를 화면에 띄우고 구글 스프레드시트에 기록한다.

## 구성
- `index.html` : 입장 체크 스캐너 (폰 브라우저, 카메라 사용 → https 필요)
- `Code.gs` : Google Apps Script 웹 앱 (판정 + 스프레드시트 기록)

## 판정 순서
1. QR 해석: `_KW` + `0` + 학번(10) + 발급시각(yyyyMMddHHmmss) + 숫자 5자리
2. 발급 10분 초과 QR → **만료** (`QR_MAX_AGE_MIN`)
3. 학과코드(학번 5~7번째 자리)가 인융대가 아니면 → **비대상**
   - 202/402 컴정공, 203/403 소프트, 204/404 정융, 205/405/406 로봇 (`설정` 탭)
4. 이미 입장 기록이 있으면 → **중복** (QR·수기 입력 모두 학번 기준)
5. 학생회비 미납부자가 `설정!F2`(기본 16:45) 전에 오면 → **대기**
6. 그 외 → **입장**

## 시트 탭
- `설정` : 학과코드 목록, 미납부자 입장 시각
- `명단` : 학생회비 납부자 명단 (학번 / 이름 / 학부)
- `입장기록` : 시각 / 학번 / 이름 / 학부 / 결과 / 기기 / QR 원문 / 학생회비

## 배포 메모
- Apps Script: 웹 앱, 실행 사용자 "나", 액세스 "모든 사용자"
- 코드 수정 후에는 배포 관리 → 수정 → 새 버전으로 업데이트해야 같은 URL에 반영됨
- `index.html`의 `API_URL`, `KEY`는 `Code.gs`의 웹 앱 URL, `SECRET`과 같아야 함
