# 인융인의 밤 입장 체크

인공지능융합대학 학생회 하성 「인융인의 밤」 입장 체크. 운영진이 폰으로 도서관 모바일 이용증 QR을 찍으면 입장 가능 여부를 보여준다.

## 구성
- `index.html` : 스캐너 화면 (GitHub Pages). 운영진 Google 로그인 후에만 스캔 가능. 학번·이름을 표시하거나 저장하지 않음.
- `Code.gs` : Apps Script 판정 서버. Google ID 토큰을 검증하고 등록된 운영진 계정만 허용. 비밀값·시트 ID는 코드가 아니라 스크립트 속성에만 있음.

## 판정
1. QR 형식 확인 (`_KW` + 0 + 학번 10자리 + 발급시각 14자리 + 숫자) → 아니면 **인식 불가**
2. 발급 10분 초과 → **만료**
3. `설정!F3`(기본 16:30) 전 → **아직 입장 전**
4. 납부자 명단에도 없고 학과코드도 인융대가 아니면 → **입장 대상 아님**
5. 이미 입장 기록이 있으면 → **이미 입장함**
6. 미납부자가 `설정!F2`(기본 16:45) 전에 오면 → **잠시 대기**
7. 그 외 → **입장 OK**

## 비공개 시트 (소유자만 접근)
- `설정` : 학과코드, 입장 시각
- `명단` : A열에 납부자 학번만
- `입장기록` : 시각 / 결과 / 납부 여부 / 복원 불가 판정키 (학번·이름·QR 원문 없음)
